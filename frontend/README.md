# Scrib frontend

The frontend is a React and TypeScript app built with Vite. It shows the room lobby, shared letter board, timer, player scores, and round results.

## Run locally

From this directory, run:

~~~bash
npm install
npm run dev -- --host 127.0.0.1
~~~

Open <http://127.0.0.1:5173/>. By default, the frontend connects to the backend at http://127.0.0.1:8001.

For the game rules, backend setup, and full project overview, see the root README.
